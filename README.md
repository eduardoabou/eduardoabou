## 📂 Projetos em destaque

### 💊 FarmaConnect — Automação farmacêutica

Aplicativo Android desenvolvido como Trabalho de Conclusão de Curso, voltado à automação de etiquetas farmacêuticas.

**Principais recursos:**
- Pesquisa e seleção de medicamentos.
- Geração de etiquetas com QR Code para acesso a bulas digitais.
- Impressão de etiquetas por Bluetooth.
- Armazenamento local de informações e integração com Supabase.

**Tecnologias:** React Native, TypeScript, SQLite, Supabase e Bluetooth.

[🔗 Conhecer o FarmaConnect](https://github.com/eduardoabou/FarmaConnect)

### 📄 Automação de documentos fiscais — NFS-e

Desenvolvimento de solução para automatizar a consulta e o download de Notas Fiscais de Serviço Eletrônicas, reduzindo atividades manuais e facilitando processos fiscais.

**Tecnologias:** C#, WPF e Python.
